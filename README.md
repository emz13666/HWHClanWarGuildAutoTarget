# 🎯 HWHClanWarGuildAutoTarget (v4.28)

Автоматическое назначение целей в Войне Гильдий (Clan War) для всех членов гильдии на основе истории прошлых побед.

## 📋 Описание

Этот пользовательский скрипт (Userscript) для **Tampermonkey** / **Violentmonkey** анализирует журнал боёв Войны Гильдий и автоматически назначает цели тем членам гильдии, у которых есть попытки атаки. 

Скрипт назначает цель **только если**:
1. Игрок ранее **полностью побеждал** этого защитника (+20 очков, а не добив).
2. Состав команды защиты (герои или титаны) **не изменился** с момента той победы. Расстановка питомцев-покровителей не учитывается.
3. Слот защитника **свободен** (не атакован сегодня, не назначен другому игроку, не имеет статус `defeated`).

## ✨ Возможности

- 🧠 **Умный подбор**: Сравнивает пачки героев с героями, а титанов с титанами.
- 📊 **Учёт попыток**: Назначает по 1 цели на каждую доступную попытку игрока (если у игрока 2 попытки, скрипт найдёт для него 2 разные цели).
- 🗄️ **Расширенная база данных**: Сохраняет историю *всех* боёв в `localStorage` (до 90 дней) для будущей аналитики, но при назначении целей строго фильтрует только полные победы.
- 🧹 **Умная очистка**: Автоматически игнорирует и не сохраняет "пустые" бои (незащищённые позиции с `replayId: 0`), предотвращая разрастание базы и экономя место.
- 💾 **Экспорт и импорт**: Встроенные кнопки для сохранения истории в JSON-файл и её загрузки (удобно при смене браузера или очистке кэша).
- 🛡️ **Безопасность**: Игнорирует цели, которые уже были атакованы сегодня или имеют статус `inBattle` / `defeated`.
- 🖥️ **Неинтрузивный интерфейс**: Информационная панель справа сверху с прогрессом, которую можно свернуть, перетащить или закрыть. Автоматически скрывается через 5 секунд после завершения.
- 🔄 **Фоновое обновление**: Сбор истории боёв происходит при каждом запуске скрипта, даже если Война Гильдий в данный момент не активна.

## 📦 Установка

1. Установите расширение для браузера: [Tampermonkey](https://www.tampermonkey.net/) или [Violentmonkey](https://violentmonkey.github.io/).
2. Убедитесь, что у вас установлен и работает основной скрипт [HeroWarsHelper (HWH)](https://greasyfork.org/ru/scripts/450693-herowarshelper).
3. Нажмите на кнопку **"Raw"** или перейдите по прямой ссылке на скрипт:
   👉 [Установить HWHClanWarGuildAutoTarget](https://raw.githubusercontent.com/emz13666/HWHClanWarGuildAutoTarget/main/HWHClanWarGuildAutoTarget.user.js)
4. Подтвердите установку в открывшемся окне менеджера скриптов.

## 🚀 Использование

1. Зайдите в игру Hero Wars.
2. Откройте меню **HeroWarsHelper** (обычно кнопка в интерфейсе игры).
3. Перейдите на вкладку **"Действия"**.
4. Нажмите кнопку **🎯 Авто-цели для гильдии**.
5. Наблюдайте за процессом в информационной панели справа. 
   - В заголовке панели есть кнопки 💾 (сохранить историю в файл) и 📂 (загрузить историю из файла).
6. По завершении панель покажет итоговый отчёт и автоматически закроется через 5 секунд (если вы не начнёте с ней взаимодействовать).

## ⚙️ Технические детали

- **Хранение данных**: История хранится в `localStorage` под ключом `HWH_CW_History_Log_v1`. Максимальный срок хранения — 90 дней. Пустые дни (без реальных боёв) не создаются.
- **Мониторинг**: При каждом запуске скрипт выводит в консоль браузера (F12) подробную статистику занятого и свободного места в `localStorage`, предупреждая о приближении к лимиту (80%+).
- **Совместимость**: Требуется наличие глобальных объектов `HWHClasses`, `HWHFuncs`, `HWHData` и `Caller` от HeroWarsHelper.
- **Регистрация**: Скрипт официально регистрируется в HWH через `HWHFuncs.addExtentionName`.
