# 🎯 HWHClanWarGuildAutoTarget

Умное назначение целей в Войне Гильдий для всех участников гильдии на основе истории прошлых полных побед.

## 📋 Описание

Этот пользовательский скрипт (Userscript) для **Tampermonkey** / **Violentmonkey** анализирует журнал боёв Войны Гильдий и автоматически расставляет цели тем участникам гильдии, у которых есть свободные попытки атаки.

Скрипт использует **4-уровневый каскадный подбор** — от самого точного совпадения к менее точному:

| Уровень | Иконка | Условие |
|---|---|---|
| `exact` | ✅ | Тот же защитник + тот же пак + те же питомцы-покровители |
| `sameDefenderMinor` | ⚠️ ~пит | Тот же защитник + те же герои, но другие питомцы-покровители |
| `otherDefenderExact` | 🔄 ≠ID | Другой защитник, но пак полностью совпадает (герои + питомцы) |
| `otherDefenderMinor` | 🔄⚠️ ≠ID~пит | Другой защитник, герои совпадают, питомцы — нет |

Кандидат на слот назначается только если у него **есть полная победа** над защитником в базе (20 очков) и **свободные попытки**. Скрипт никогда не назначит больше попыток, чем есть у игрока.

## ✨ Возможности

- 🎯 **4-уровневый каскад**: от точного совпадения к приблизительному. Если точных матчей нет, скрипт подберёт лучший вариант из доступных.
- 🔢 **Точный учёт попыток**: корректно распознаёт цели, назначенные вручную до запуска (`targetMarkingUserId`) и параллельные метки (`attackerId`). Не назначает больше попыток, чем есть, и не дублирует слоты. Если `attackLimit` на сервере всё же срабатывает — игрок исключается из прогона с предупреждением в логе.
- 🗄️ **IndexedDB-хранилище**: история боёв и кэш реплеев хранятся в IndexedDB (`HWHClanWarGuildAutoTarget`). Автоматическая миграция из `localStorage`. При повреждении БД пересоздаётся автоматически.
- 📼 **Трёхуровневый кэш реплеев**: память → IndexedDB → сервер. Повторные запуски работают мгновенно, снижается нагрузка на сервер.
- 🔧 **Ручная догрузка реплеев**: кнопка 🔧 в панели запускает загрузку всех недостающих реплеев **без лимита**. Повторное нажатие — остановка. По завершении выводится статистика БД.
- ⚔️ **Ручной контроль альтернатив**: альтернативные цели ищутся и назначаются **только по нажатию ⚔️** в панели.
- 💾 **Бэкап и восстановление**: кнопки 💾 и 📂 экспортируют/импортируют единый JSON (история + кэш + назначения) с версионированием и безопасным слиянием.
- 🏷️ **Понятные названия**: в логах — названия зданий (`Ак.Магов-1`, `Мост-3`, `Цитадель-7`), полные составы паков атакующих и защитников (герои + питомцы + покровители).
- 📊 **Диагностика**: при каждом запуске выводится статистика IndexedDB (дни истории, полные/неполные реплеи, занятое место). При превышении лимита реплеев внизу лога дублируется предупреждение и напоминание догрузить 🔧.
- 🗓️ **История за 90 дней**: всё, что старше, автоматически вычищается при сохранении.
- 🧹 **Умная очистка**: «пустые» бои (`replayId: 0`) не сохраняются и не засоряют историю.
- 🔐 **Проверка прав**: кнопки расстановки видны только при `clanRole 255` (глава) или `clanRole 4` (генерал). Остальные могут смотреть свои цели и цели гильдии через 📌 / 📋.
- 🛡️ **Безопасность**: уже атакованные сегодня слоты (`status != 'ready'`) и добитые (`status == 'defeated'`) игнорируются.
- 🖥️ **Неинтрузивная панель**: плавающая панель справа сверху — можно свернуть, перетащить, закрыть. Закрывается сама через 10 секунд после завершения, если с ней не взаимодействовать.
- 📦 **Архивация назначений**: при превышении 50 МБ старые записи (старше 180 дней) архивируются в JSON-файл и удаляются из IndexedDB. Кнопка 📊 в панели позволяет посмотреть статистику и запустить архивацию вручную.

## 📦 Установка

1. Установите расширение: [Tampermonkey](https://www.tampermonkey.net/) или [Violentmonkey](https://violentmonkey.github.io/).
2. Убедитесь, что у вас установлен и работает основной скрипт [HeroWarsHelper (HWH)](https://greasyfork.org/ru/scripts/450693-herowarshelper).
3. Установите скрипт одним из способов:
   - 👉 [Установить с GitHub](https://raw.githubusercontent.com/emz13666/HWHClanWarGuildAutoTarget/main/HWHClanWarGuildAutoTargetCascade.user.js)
   - 👉 [Установить с GitVerse](https://gitverse.ru/api/repos/emz13/HWHClanWarGuildAutoTarget/raw/branch/main/HWHClanWarGuildAutoTargetCascade.user.js)
4. Подтвердите установку в менеджере скриптов.

## 🚀 Использование

1. Зайдите в игру Hero Wars и откройте окно Войны Гильдий.
2. Откройте меню **HeroWarsHelper** → вкладка **«Действия»**.
3. Нажмите кнопку **🎯 Авто-цели ВГ**.
4. Выберите действие в появившемся попапе:
   - **⚔️ Расставить ВГ** — запустить каскадный подбор и назначить цели.
   - **❌ Снять ВГ** — снять активные метки со слотов, где ещё не было боя (история, кэш и база назначений при этом **не трогаются**).
   - **📋 Открыть панель** — открыть/показать плавающую панель с кнопками управления.

### Кнопки панели

| Кнопка | Действие |
|---|---|
| 🎯 | Меню действий (расставить/снять/панель) |
| 💾 | Бэкап: история + кэш + назначения в JSON |
| 📂 | Импорт бэкапа (с мержем) |
| ⚔️ | Альтернативные назначения для оставшихся слотов |
| 🔧 | Загрузка всех реплеев без лимита (повторное нажатие — остановка) |
| 📋 | Все назначения за текущий день |
| 📌 | Мои невыполненные назначения |
| 📤 | Экспорт назначений в отдельный файл |
| 📊 | Размер IndexedDB + архивация старых записей |
| — | Свернуть/развернуть панель |
| ✕ | Закрыть панель |

5. После расстановки панель покажет итоговый отчёт и автоматически закроется через 10 секунд (если с ней не взаимодействовать).
6. Если остались свободные слоты и попытки — станет активной кнопка ⚔️, нажмите её для поиска альтернатив.
7. Если в логе появилось предупреждение про неполные реплеи или лимит — нажмите 🔧, чтобы догрузить полные составы.

### Попап при входе

Если `SHOW_ASSIGNMENTS_ON_START = true` (по умолчанию), при входе в игру показывается попап с вашими невыполненными назначениями. В нём:
- активные цели (с составами паков, питомцами, покровителями);
- «переназначенные» — слоты, которые вы получили, но их успел атаковать кто-то другой. Попытка освободилась, обратитесь к генералу/командующему за новой целью.

Кулдаун попапа — 30 минут (`POPUP_COOLDOWN_MINUTES`).

## ⚙️ Технические детали

### Хранение данных

- **История и кэш реплеев**: IndexedDB `HWHClanWarGuildAutoTarget`.
  - `history` — история по дням, ключ `<season>_<day>`, лимит **90 дней**.
  - `replays` — кэш реплеев, ключ `<replayId>`, лимит **3000 записей**.
- **Назначения**: отдельная база `HWH_CW_Assignments`, store `assignments`, ключ `<season>_<day>_<slotId>`. Лимит `KEEP_ASSIGNMENTS_DAYS = 365`, порог предупреждения 30 МБ, архивация старше 180 дней при превышении 50 МБ.
- **Миграция**: из `localStorage` (ключи `HWH_CW_History_Log_v1`, `HWH_CW_Replay_Cache_v1/v2`) при первом запуске. Старые ключи удаляются только после успешного переноса; при ошибке повтор при следующем запуске.
- **Фолбэк**: если IndexedDB недоступен — скрипт работает на `localStorage`.

### Лимиты и пороги

| Константа | Значение | Смысл |
|---|---|---|
| `MAX_REPLAY_CACHE_ENTRIES` | 3000 | максимум реплеев в кэше |
| `MAX_HISTORY_DAYS` | 90 | глубина истории |
| `maxNew` (по умолчанию) | 100 | максимум реплеев за один прогон расстановки |
| `maxNew` (🔧) | `Infinity` | без лимита |
| `CASCADE_MIN_WINS` | 1 | минимум побед для кандидата |
| `POPUP_COOLDOWN_MINUTES` | 30 | кулдаун стартового попапа |
| `AUTO_CLOSE_DELAY_SECONDS` | 10 | автозакрытие панели |

### Точечная запись

При обновлении истории и кэша в IndexedDB пишутся **только изменённые** дни и реплеи — это ускоряет работу и снижает износ хранилища.

### Очистка

- `sm_*`-ключи (legacy от старой версии, до 4.57) автоматически вычищаются вместе с ВГ-историей: сначала как «лишние» при превышении 90 дней, затем при prune.
- `replayId`, не привязанные к ВГ-истории, вычищаются при превышении 3000 записей.
- «Пустые» бои (`replayId: 0`) не сохраняются.

### Совместимость

- Требуются глобальные объекты `HWHClasses`, `HWHFuncs`, `HWHData`, `Caller` от HeroWarsHelper.
- Скрипт официально регистрируется в HWH через `HWHFuncs.addExtentionName`.
- **Только ВГ**: поддержка СМ (Cross-Clan War) удалена в v4.57. Legacy-данные СМ в IndexedDB (`mode: 'crossClanWar'`) не показываются в списках и вычищаются при архивации.
